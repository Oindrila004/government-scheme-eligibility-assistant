# Government Form & Scheme Eligibility Assistant

An AI-powered web application that helps users understand government schemes, check personalized eligibility, and navigate application procedures through simple, citation-backed explanations.

## Project Overview

Users can upload official government scheme notifications in PDF format and enter their personal information. The system extracts eligibility criteria, compares them with user information, and provides understandable explanations.

## Key Features

- Government scheme PDF upload
- Automatic PDF text extraction
- AI-powered scheme summarization
- Personalized eligibility assessment
- Required document checklist
- Application procedure guidance
- RAG-based question answering
- Source and page citations
- User authentication and history
- Subscription-based PDF uploads
