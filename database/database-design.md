# Database Design

## Database
government_scheme_assistant

## DBMS
PostgreSQL

## Tables

1. app_user
   Stores user account information.

2. user_profile
   Stores information required for scheme eligibility.

3. scheme
   Stores government scheme information.

4. eligibility_rule
   Stores scheme eligibility conditions.

5. scheme_document
   Stores official scheme document metadata.

6. user_document
   Stores user-uploaded document metadata.

7. eligibility_assessment
   Stores user assessment history.

8. assessment_result
   Stores individual scheme assessment results.
